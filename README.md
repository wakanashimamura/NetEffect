# NetEffect

**NetEffect** is a network effect visualization project written in **C++** using the **Qt framework**.

## Demo

![NetEffect Demo](demo.gif)

## Controls


| Mouse button                 | Action                                          |
| ---------------------------- | ----------------------------------------------- |
| **Left Mouse Button (LMB)**  | Add a point at the cursor position              |
| **Right Mouse Button (RMB)** | Remove the point closest to the cursor position |
